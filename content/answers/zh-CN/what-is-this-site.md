**这是一个示例站点。** 内容以学习与实践记录为主，把文章、随笔、项目和常见问题放在同一个地方。

站点用 Astro 和 Starlight 搭建，基于 Refined-X 模板：内容写在 Markdown 与 YAML 里，构建时除了生成给人读的页面，还会生成同一份内容的 Markdown 镜像、`llms.txt` 与 JSON 接口，方便搜索引擎和 AI Agent 直接读取。

想了解人，看[关于页](/about/)；想了解做过什么，看[项目页](/projects/)；想找具体答案，用站内提问，或者直接翻[常见问题](/answers/)。
