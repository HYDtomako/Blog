**这是 HYD 的个人站点。** 内容以学习过程为主：AI 全栈、LLM 与 Agent 相关的笔记和文章，加上做出来的项目和随手写下的随笔。

站点用 Astro 和 Starlight 搭建，基于 Refined-X 发布模板：文章、随笔、问答和项目都写在 Markdown 与 YAML 里，构建时除了生成给人读的页面，还会生成同一份内容的 Markdown 镜像、llms.txt 和 JSON 接口，方便搜索引擎和 AI Agent 直接读取。

想了解人，看[关于页面](/about/)；想了解做过什么，看[项目页](/projects/)；想找具体答案，用站内提问，或者直接翻[常见问题](/answers/)。
