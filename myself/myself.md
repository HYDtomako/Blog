请基于我目前的个人网站 https://hydblog.xyz/，重新设计并实现一个高质感的全屏 Intro / Preloader。

我希望这个开屏动画参考“深海潜水仪表 / 深海压力表”的视觉语言，而不是普通网页 Loading。

====================
一、核心概念
====================

整个开屏需要讲述一个完整的小故事：

“设备启动 → 开始下潜 → 深度不断增加 → 水压逐渐升高 → 进入深海 → 到达目标深度 → HYD 从深海中出现 → 仪表界面展开并自然过渡到网站首页。”

用户看到的感觉应该是：

“我正在潜入一个叫 HYD 的深海世界。”

而不是：

“网站正在加载。”

这是一个 Intro，不是简单的 Loading。

====================
二、整体视觉风格
====================

参考：
- 深海潜水仪表
- 专业压力表
- 深海探测器
- 科学仪器
- 极简 HUD
- 水下设备
- 高端工业仪器 UI

视觉关键词：

deep sea
diving instrument
pressure gauge
depth meter
underwater
scientific instrument
minimal HUD
ocean blue
cinematic
precision
premium
calm
elegant
minimal

配色：

- 深海蓝
- 海洋蓝
- 蓝灰
- 少量冷白
- 极少量浅青蓝

不要使用纯黑。

不要做成：
- Cyberpunk
- Hacker
- Matrix
- 游戏 HUD
- 军事雷达
- 炫酷霓虹科技风

重点是：

“真实、安静、精密的深海仪器”。

====================
三、动画时间
====================

整个 Intro 总时长控制在：

6～8 秒。

不要压缩到 2～3 秒。

这个动画需要有“过程感”和“呼吸感”。

节奏应该是：

慢启动
→
逐渐加速
→
接近目标时减速
→
短暂停顿
→
HYD 出现
→
缓慢转场

用户应该能够清楚地看到整个过程。

不要让数字、刻度、文字一闪而过。

====================
四、第一阶段：仪器启动
====================

时间：

0.0s ～ 1.2s

初始背景是一片安静的深海蓝。

中央逐渐出现一个圆形深海压力仪表。

一开始仪表几乎不可见。

然后：

- 外圈轮廓出现
- 刻度逐渐亮起
- 内圈出现
- 指针启动
- 少量辅助线出现
- 仪表中心出现微弱光晕

初始数据显示：

DEPTH
000 m

PRESSURE
1.0 BAR

可以再加入：

TEMP
18.0 °C

底部出现：

SYSTEM INITIALIZED

但文字必须非常克制。

不要塞太多内容。

这一阶段应该有一种：

“一个沉睡中的深海设备正在启动。”

的感觉。

====================
五、第二阶段：开始下潜
====================

时间：

1.2s ～ 2.5s

开始正式下降。

深度缓慢增加：

000 m
→ 080 m
→ 160 m
→ 280 m
→ 420 m
→ 650 m

压力同步变化。

例如：

1.0 BAR
→
9.0 BAR
→
17.0 BAR
→
29.0 BAR
→
43.0 BAR
→
66.0 BAR

数字必须使用平滑动画。

不要瞬间跳跃。

建议数字像真实数字仪表一样连续滚动。

中央仪表的：
- 指针
- 刻度
- 扫描线
- 环形进度

全部同步运动。

底部状态：

DESCENDING

====================
六、第三阶段：进入深海
====================

时间：

2.5s ～ 4.2s

随着深度继续增加：

650 m
→
900 m
→
1200 m
→
1500 m
→
1750 m
→
1900 m

压力也继续增加。

背景逐渐加深：

浅海蓝
→
海洋蓝
→
深海蓝

这里不要直接把背景变黑。

必须保留蓝色。

可以增加非常轻微的：
- 水下漂浮颗粒
- 柔和光束
- 很淡的波纹
- 极细微的浮动噪点

但是这些只能作为氛围。

不要加入：
- 鱼
- 潜水员
- 珊瑚
- 海底城市
- 海怪
- 大量 3D 模型

视觉主体始终是：

“深海仪表”。

状态文字逐渐变化：

DESCENDING

↓

PRESSURE RISING

↓

DEEP WATER

====================
七、第四阶段：接近终点
====================

时间：

4.2s ～ 5.2s

深度开始减速。

数字：

1900 m
→
1940 m
→
1970 m
→
1985 m
→
1995 m
→
2000 m

此时仪表动画逐渐放慢。

整个画面也逐渐变得安静。

最终显示：

DEPTH
2000 m

PRESSURE
201.0 BAR

TEMP
4.2 °C

然后出现：

DEPTH REACHED

这里一定要停顿大约 0.5 秒。

不要马上进入下一阶段。

这个停顿是整个动画非常重要的“呼吸点”。

用户需要明显感受到：

“到底了。”

====================
八、第五阶段：HYD 出现
====================

时间：

5.2s ～ 6.0s

到达 2000m 后。

仪表中心原本的数字慢慢消失。

然后：

H

出现。

稍微停顿。

变成：

HY

再出现：

HYD

或者直接通过很慢的字符显现 / 淡入完成。

HYD 必须是整个 Intro 第一次真正出现的核心品牌。

不要一开始就把 HYD 放在中央。

要让它像是在深海中被“发现”。

HYD 字体：

- 极简
- 现代
- 无衬线
- 轻微字距
- 白色或冷白
- 非常轻的蓝色辉光

不要做 Logo 爆炸。

不要做巨大霓虹字。

只需要：

安静地出现。

下面可以出现：

BELOW THE SURFACE

====================
九、第六阶段：进入网站
====================

时间：

6.0s ～ 7.5s

HYD 出现后。

中央圆形仪表开始扩大。

仪表的圆环：

向外扩张

刻度：

向四周散开

辅助线：

慢慢延伸

整个圆形仪表最终覆盖整个屏幕。

然后像一个“水下镜头”逐渐展开。

视觉上的感觉：

仪表盘
→
水波
→
整个屏幕

最终自然过渡到 hydblog.xyz 首页。

不要直接：

“fade out → 首页”。

必须有连续的视觉关系。

让用户感觉：

“刚才的深海仪表，就是这个网站世界的一部分。”

====================
十、Homepage 过渡
====================

进入首页以后：

不要突然改变配色。

保持：
- 蓝色
- 海洋感
- 清澈
- 极简
- 留白

首页视觉应该像：

“潜水结束后，终于看到 HYD 的真实世界。”

可以让最后的圆环变成：
- Hero 背景的一道光
- 一个水波
- 一条细线
- 一个轻微扩散的圆

然后完全融入首页。

====================
十一、仪表 UI 细节
====================

中央圆形仪表应该是视觉核心。

建议包含：

外圈：
大量细密刻度

第二圈：
较粗刻度

第三圈：
细扫描环

中央：
DEPTH 数值

外围：
PRESSURE

TEMP

状态：

DESCENDING
PRESSURE RISING
DEEP WATER
DEPTH REACHED

四个角可以加入极少量装饰：

DEVICE
SEA LEVEL
LAT
LONG
SYSTEM

但是全部降低透明度。

不要让四角信息抢主视觉。

====================
十二、运动设计
====================

这一点非常重要：

动画不能“快”。

应该有明显的 easing。

推荐：

- easeInOut
- cubic-bezier
- slow start
- slow end

数字：
平滑变化

刻度：
逐渐出现

指针：
物理感转动

背景：
缓慢变化

文字：
淡入淡出

到达 2000m 后：
明显减速

整体应该有“机械仪器”的运动感。

不要像普通网页动画。

====================
十三、声音（可选）
====================

如果实现声音：

只允许非常轻微的：

- 深海低频环境声
- 仪器启动声
- 很轻的机械提示音
- 极轻微的水下声音

不要使用：
- EDM
- 强烈 BGM
- 游戏音效
- 夸张机械音

默认应该静音，并尊重浏览器自动播放限制。

====================
十四、交互与性能
====================

必须支持：

1. Skip Intro

右下角：

SKIP INTRO →

但要非常低调。

2. 第一次访问播放完整 Intro。

3. 已访问过网站后：

可以通过 localStorage 记录。

第二次访问：
- 直接进入首页
或者
- 只显示一个 0.5～1 秒的简版 Intro

4. prefers-reduced-motion：

如果用户开启减少动画：

直接跳过复杂动画。

5. 手机端：

必须完整适配。

6. Intro 不能影响：

- SEO
- 首屏内容
- 页面交互
- 网站加载速度

7. 所有动画尽可能使用：

transform
opacity
CSS animation
requestAnimationFrame

避免不必要的高性能消耗。

完成。

2000m。

DEPTH REACHED

HYD

最后进入个人网站。

整个 Intro 应该有：

安静
深沉
高级

“我正在潜入 HYD 的世界。”
